React Native MVC skeleton for multi-tenant SaaS.

New: `frontend/spa` contiene una SPA React (Vite) mínima para login, creación de tenants como SUPER_ADMIN y listados básicos de usuarios/pedidos/pagos/caja para ADMIN. Ejecuta `npm install && npm run dev` dentro de esa carpeta y apunta a `VITE_API_URL` si necesitas un backend distinto a `http://localhost:3000`.
